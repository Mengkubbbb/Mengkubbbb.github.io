## 2. วิธีคอมไพล์และรัน (คัดลอกได้เลย)

```bash
cd Minecraft-MMO-Academy/projects/03-java-lab

# 1) ตรวจว่ามี JDK 25
java -version
javac -version

# 2) คอมไพล์ทั้งหมดไปที่โฟลเดอร์ out/
mkdir -p out
javac -d out $(find src -name "*.java")

# 3) รัน (ชื่อคลาสเต็มพร้อมแพ็กเกจ)
java -cp out com.mengkub.javalab.Main

# 4) ล้างผลลัพธ์เมื่อต้องการคอมไพล์ใหม่
rm -rf out
```

**ทำไมต้อง `-d out`?** เพื่อแยกไฟล์ `.class` (ผลลัพธ์จากการคอมไพล์) ออกจากไฟล์ `.java` (โค้ดที่เราเขียน) — ทำให้โปรเจกต์สะอาด

**ทำไมต้อง `-cp out` ตอนรัน?** เพราะ Java ต้องรู้ว่าไปหาไฟล์ `.class` ที่ไหน (`-cp` = classpath)

## 4. แนวคิดที่ได้จากโปรเจกต์นี้

| ไฟล์ | สอนอะไร |
| --- | --- |
| `Rarity.java` | `enum` ใช้กับค่าที่มีจำกัด (COMMON/RARE/EPIC/LEGENDARY) + เก็บตัวคูณราคาไว้ข้าง ๆ |
| `Item.java` | ฟิลด์ private + constructor ที่ตรวจสอบค่า (`if (damage < 0) throw ...`) |
| `Player.java` | ฟิลด์หลายชนิด, `ArrayList<Item>`, เมธอดคำนวณ (level up) |
| `LootTable.java` | ลูป + อาร์เรย์ + น้ำหนัก (cumulative) เหมือนใน Month 2 แต่เขียนด้วย Java |
| `Combat.java` | เมธอดคืนค่าเป็นออบเจกต์ผลลัพธ์ (เตรียมเป็น `record` ใน Month 4) |
| `Main.java` | เมนูด้วย `Scanner` + `switch` + ลูป `while` |

## 6. ผลการทดสอบของครู

| คำสั่ง | ผลที่คาดหวัง |
| --- | --- |
| `javac -d out $(find src -name "*.java")` | คอมไพล์ผ่าน ไม่มี error (อาจมี warning เล็กน้อย) |
| `java -cp out com.mengkub.javalab.Main` | เมนูแสดงผลและใช้งานได้ |
| ป้อน `2` ที่เมนู | เห็นรายการไอเทมที่สุ่มได้ 10 ครั้ง |
| ป้อน `0` | โปรแกรมจบการทำงานด้วย exit code 0 |

> ⚠️ ถ้าคอมไพล์ไม่ผ่าน ให้คัดลอกข้อความ error ทั้งก้อนมาถามครูด้วยคำสั่ง `DEBUG`
> (อย่าลบ `out/` ทิ้งก่อนดู error — error บอกไฟล์และบรรทัดที่ผิด)
