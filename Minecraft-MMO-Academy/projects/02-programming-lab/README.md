## 2. วิธีรัน

```bash
cd Minecraft-MMO-Academy/projects/02-programming-lab/scripts
chmod 755 *.sh

./loot-table.sh 10                 # สุ่มรางวัล 10 ครั้ง
./loot-table.sh 1000 --summary     # สุ่ม 1000 ครั้ง + สรุปผลว่าออกบ่อยแค่ไหน
./damage-sim.sh                    # ต่อสู้ 1 รอบ
./damage-sim.sh --seed 42 --rounds 5   # ทำซ้ำได้ด้วย seed (สำคัญมากสำหรับทดสอบเกม)
./exp-curve.sh 1 10                # ตาราง EXP เลเวล 1-10
./exp-curve.sh --compare           # เทียบสูตร EXP แบบเส้นตรงกับแบบทวีคูณ
```

## 3. แนวคิดที่ได้จากแต่ละ script

### 3.1 `loot-table.sh`
- **Weighted random:** ไอเทมที่มีน้ำหนักมากกว่าจะออกบ่อยกว่า โดยคำนวณจาก **ผลรวมสะสม** (cumulative sum)
- **ตรวจข้อมูลก่อนใช้:** ถ้าน้ำหนักรวมเป็น 0 หรือติดลบ → แจ้งเตือนและหยุด (ไม่ให้เกิดการหารด้วยศูนย์)
- **สรุปผล:** นับจำนวนครั้งที่ออกแต่ละไอเทม เพื่อเทียบกับโอกาสที่ออกแบบไว้ → **นี่คือการทดสอบสมดุลเกมขั้นต้น**
- **สิ่งที่ควรเห็น:** สุ่ม 1,000 ครั้ง สัดส่วนที่ได้ควรใกล้เคียงน้ำหนักที่ตั้งไว้ (ไม่เป๊ะ — เพราะเป็นความน่าจะเป็น)

### 3.2 `damage-sim.sh`
- **ลูป + เงื่อนไข:** ต่อสู้ไปจนมีฝ่ายหนึ่งเลือด ≤ 0
- **สูตรดาเมจ:** `(โจมตี - ป้องกัน/2) × ตัวคูณคริติคอล` พร้อมค่า `max(1, ...)` กันดาเมจติดลบ
- **seed:** ใช้ `--seed` เพื่อให้สุ่มซ้ำได้ (deterministic) — จำเป็นมากเวลาแก้บั๊กการต่อสู้ใน Month 9
- **บันทึกผล:** เขียนผลการต่อสู้ลง `notes/combat-log.txt` เพื่อย้อนดูได้

### 3.3 `exp-curve.sh`
- **สูตรเกม:** `EXP ที่ต้องใช้ = 100 × level^1.5` (แบบทวีคูณ) เทียบกับ `100 × level` (แบบเส้นตรง)
- **why:** ทำให้เห็นว่าเกม MMO ต้องใช้สูตรแบบทวีคูณ เพื่อให้การเลเวลสูงขึ้นยากขึ้นตามลำดับ
- **การทดสอบ:** ตรวจว่า EXP ไม่มีค่าติดลบและไม่สูงเกินขอบเขตที่คำนวณไหว

## 4. แบบฝึกหัดของโปรเจกต์

| # | งาน | เกณฑ์ผ่าน |
| --- | --- | --- |
| 1 | เพิ่มไอเทมใหม่ 2 ชิ้นใน `loot-table.sh` แล้วทดสอบว่าน้ำหนักรวมยังเป็น 100 | รัน `--summary` แล้วสัดส่วนสมเหตุสมผล |
| 2 | เปลี่ยนสูตรดาเมจใน `damage-sim.sh` ให้มี "โอกาสพลาด 10%" | ทดสอบด้วย seed เดียวกันแล้วผลเปลี่ยนอย่างอธิบายได้ |

| 4 | เขียน `boss-sim.sh` เอง: บอสมี 3 เฟส เปลี่ยนพฤติกรรมเมื่อเลือดต่ำกว่า 66% และ 33% | มี log แสดงการเปลี่ยนเฟสจริง |
