## 1. โครงสร้างโปรเจกต์

```text
01-linux-lab/
├── README.md            ← ไฟล์นี้ (วิธีใช้ + ผลการทดสอบ)
└── scripts/
    ├── first-script.sh      ← Day 02: ตัวแปร, argument, ตรวจสอบ input
    ├── server-check.sh      ← Day 07: ตรวจสุขภาพเครื่อง 7 หมวด
    ├── backup.sh            ← Day 18: สำรองข้อมูลอย่างปลอดภัย (dry-run เป็นค่าเริ่มต้น)
    └── server-start.sh      ← Day 26: เปิดเซิร์ฟเวอร์ (ตรวจ Jar/RAM/พอร์ตก่อนรัน)
```

> ⚠️ **หมายเหตุโฟลเดอร์ทำงาน:** หลักสูตรให้ผู้เรียนทำงานใน `~/minecraft-mmo-dev/` ของตัวเอง
> โฟลเดอร์นี้ใน repo เป็น **ชุดอ้างอิง** ไว้เทียบกับงานของผู้เรียน (ให้พิมพ์เองก่อนแล้วค่อยเทียบ)

## 2. วิธีรัน (คัดลอกได้เลย)

```bash
# 1) เข้าโฟลเดอร์โปรเจกต์ (ปรับพาธตามที่คุณวางไฟล์ไว้)
cd ~/minecraft-mmo-dev/scripts      # หรือ cd <repo>/Minecraft-MMO-Academy/projects/01-linux-lab/scripts

# 2) ให้สิทธิ์รัน (ทำครั้งเดียว)
chmod 755 first-script.sh server-check.sh backup.sh server-start.sh

# 3) รันทีละตัว
./first-script.sh Somchai           # ต้องได้ข้อความต้อนรับ
./first-script.sh                   # ต้องได้ข้อความวิธีใช้ + exit code 1
./server-check.sh                    # ตรวจสุขภาพเครื่อง 7 หมวด
./backup.sh --help                   # อ่านวิธีใช้ (ไม่ต้องมีไฟล์ก็รันได้)
./server-start.sh --help             # อ่านวิธีใช้
```

## 3. รายละเอียดแต่ละ script

### 3.1 `first-script.sh` (Day 02)
- **ทำอะไร:** ทักทายผู้เล่นที่ใส่มาเป็น argument + แสดงเวลาเข้าเล่น
- **สอนอะไร:** shebang, `$1`, `[ -z "$1" ]`, `exit 1`

### 3.2 `server-check.sh` (Day 07)
- **ทำอะไร:** ตรวจ 7 หมวด: ระบบปฏิบัติการ, Java (ต้องเป็น 25 สำหรับ Paper 26.x), ดิสก์, RAM, CPU, พอร์ต 25565, โครงสร้างโฟลเดอร์
- **ทำอะไรไม่ทำ:** **ไม่แก้ไข** อะไรในระบบ (ปลอดภัยต่อการรันซ้ำ) และคืนค่า `exit 1` เมื่อมีปัญหา
- **ตัวเลือก:** `--quiet` (แสดงเฉพาะบรรทัดสรุป), `--help`

### 3.3 `backup.sh` (Day 18)
- **ทำอะไร:** สำรองโฟลเดอร์/ไฟล์ (เช่น `world/`, `plugins/`) ไปยัง `backups/<วันที่>/` แล้วอัปเดตไฟล์ `latest.txt`
- **ความปลอดภัย:** ทำงานแบบ **dry-run เป็นค่าเริ่มต้น** (แสดงว่าจะทำอะไร) ต้องใส่ `--apply` จึงจะคัดลอกจริง
- **ทำอะไร:** ตรวจว่าปลายทางมีพื้นที่พอ, กันไม่ให้เขียนทับซ้ำโดยไม่รู้, ไม่ลบข้อมูลเดิม

### 3.4 `server-start.sh` (Day 26)
- **ทำอะไร:** ตรวจ `paper-*.jar`, ตรวจ Java 25, ตรวจพอร์ตว่าง, ตั้งค่า RAM แล้วเปิดเซิร์ฟเวอร์
- **ความปลอดภัย:** ถ้าไม่พบ Jar จะแจ้งวิธีเตรียม (ไม่พัง), ถ้าพอร์ตถูกใช้จะไม่เปิดซ้อน, รองรับ `--test` เพื่อลองตรวจโดยไม่เปิดจริง

## 4. แบบฝึกหัดของโปรเจกต์นี้

| # | งาน | เกณฑ์ผ่าน |
| --- | --- | --- |
| 1 | แก้ `server-check.sh` ให้ตรวจ Java จาก `$JAVA_HOME` ด้วย (ไม่ใช่แค่ `PATH`) | รันได้ทั้งกรณีมี/ไม่มี `JAVA_HOME` |
| 2 | เพิ่มหมวดที่ 8: ตรวจว่า `~/minecraft-dev` เป็น Git repo หรือไม่ | รายงานถูกต้องทั้งกรณีเป็น/ไม่เป็น |
| 3 | ทำให้ `backup.sh` เก็บได้แค่ 7 สำรองล่าสุด (ลบเก่ากว่าให้เอง) | ทดสอบด้วยโฟลเดอร์ตัวอย่างและแสดงผลลัพธ์ |
| 4 | เพิ่ม `--quiet` ให้ `backup.sh` | ไม่มี output เมื่อสำเร็จ, มีเฉพาะเมื่อผิดพลาด |

## 5. วิธีทดสอบตัวเอง (checklist)

- [ ] `bash -n <ทุกไฟล์>` ผ่าน (ตรวจ syntax)
- [ ] `shellcheck` ผ่าน หรืออธิบายได้ว่าทำไมบรรทัดนั้นถูกต้อง (ถ้าติดตั้ง shellcheck ได้)
- [ ] ทุก script มี `chmod 755` และรันด้วย `./` ได้
- [ ] ทุก script มีข้อความช่วยเหลือเมื่อใส่ argument ผิด
- [ ] `server-check.sh` คืนค่า `exit 1` เมื่อเจอปัญหา (ทดสอบจริง)
- [ ] `backup.sh` ไม่คัดลอกอะไรเลยถ้าไม่ใส่ `--apply` (ทดสอบจริง)
- [ ] ไม่มี script ใดลบข้อมูลโดยไม่ถามหรือไม่แสดงคำเตือน

## 6. ผลการทดสอบของครู (สภาพแวดล้อมจริง)

> 📌 ครูทดสอบบน Linux (Ubuntu 24.04, bash 5.2) ด้วย bash 5.x เท่านั้น — **บน CachyOS (Arch) ผลลัพธ์ควรเหมือนกัน**
> ถ้าผลของคุณต่างจากนี้ ให้บันทึกลง [TROUBLESHOOTING.md](../../TROUBLESHOOTING.md)

ผลลัพธ์จริงจะถูกบันทึกในไฟล์ `docs/test-runs/` ของผู้เรียนหลังรันครั้งแรก
(ตัวอย่างคำสั่ง: `./server-check.sh && echo OK`)

| script | คำสั่งทดสอบ | ผลที่คาดหวัง |
| --- | --- | --- |
| `first-script.sh` | `./first-script.sh Somchai` | พิมพ์ข้อความต้อนรับ + เวลา |
| `first-script.sh` | `./first-script.sh; echo $?` | พิมพ์วิธีใช้ + `1` |
| `server-check.sh` | `./server-check.sh` | รายงาน 7 หมวด + สรุป + exit 0/1 |
| `server-check.sh` | `PATH=/usr/bin ./server-check.sh` | รายงานว่าไม่พบ java (ไม่พัง) |
| `backup.sh` | `./backup.sh --help` | พิมพ์วิธีใช้ + exit 0 |
| `backup.sh` | `./backup.sh` | แจ้งว่าเป็น dry-run (ไม่คัดลอกไฟล์) |
| `server-start.sh` | `./server-start.sh --test` | แจ้งว่าไม่พบ `paper-*.jar` + วิธีเตรียม |
