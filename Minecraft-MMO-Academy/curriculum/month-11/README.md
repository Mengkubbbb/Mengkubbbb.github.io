# เดือนที่ 11 — Economy, Trading, Security, Website และ Performance

**ช่วงวัน:** Day 301–330 · **บทเรียนละเอียด:** ⏳

## เป้าหมายของเดือน
เศรษฐกิจที่สมดุลและตรวจสอบได้ ระบบซื้อขายที่กันโกง ระบบรักษาความปลอดภัยที่ทดสอบจริง
เว็บไซต์/มอนิเตอร์ที่ช่วยทำงาน และประสิทธิภาพที่วัดผลได้

## สิ่งที่ต้องมีก่อนเริ่ม
- ระบบไอเทม/ตัวละคร/ดันเจี้ยนทำงาน (Month 8–10)
- มี backup/restore ที่ทดสอบแล้ว

## หัวข้อหลักในเดือนนี้
1. ออกแบบเศรษฐกิจ: faucet (เงินเข้า) vs sink (เงินออก)
2. ระบบเงิน/ธนาคาร + ทศนิยม/หน่วยเงิน
3. Transaction: ป้องกันเงินติดลบและทำรายการซ้ำ
4. Auction house: ข้อมูล, UI, การคืนไอเทมเมื่อล้มเหลว
5. Trading ระหว่างผู้เล่น (หน้าต่างแลกของ)
6. ทดสอบ race condition / dupe ในสถานการณ์จริง
7. Anti-dupe: จุดที่มักพัง (การกดรัว, การออกกลางคัน, การ crash)
8. Anti-cheat: ทำได้จริงแค่ไหน และอะไรต้องยอมรับ
9. Exploit: คำสั่ง/สิทธิ์/แพ็กเก็ต + การตรวจฝั่งเซิร์ฟเวอร์
10. ความเป็นส่วนตัวของข้อมูลผู้เล่น (เก็บเท่าที่จำเป็น) และกฎหมายที่เกี่ยวข้อง
11. การเก็บความลับ (ไฟล์ env/คีย์) และไม่ให้หลุดเข้า Git
12. เว็บ: หน้าสถิติ + ล็อกอิน + API ที่มีคีย์
13. Monitoring: TPS/RAM/error alert
14. Profiling (spark) และการลดภาระ (chunk, entity, query)
15. Load test และการทดสอบผู้เล่นพร้อมกัน

## โปรเจกต์ประจำเดือน
