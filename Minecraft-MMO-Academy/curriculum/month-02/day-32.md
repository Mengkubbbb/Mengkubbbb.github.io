# Day 32: ประเภทข้อมูล, ตัวแปร, ชนิดข้อมูลพื้นฐาน

> เป้าหมาย: ใช้ int, String, boolean, double ได้ถูกต้อง
> เวลาที่ใช้: ~1–2 ชั่วโมง | ระดับ: เริ่มต้น

## 1) ประเภทข้อมูลพื้นฐาน
| ประเภท | ใช้สำหรับ | ตัวอย่าง |
| --- | --- | --- |
| `int` | จำนวนเต็ม | `int level = 5;` |
| `double` | ทศนิยม | `double damage = 12.5;` |
| `boolean` | จริง/เท็จ | `boolean op = true;` |
| `String` | ข้อความ | `String name = "Eclipse";` |
| `char` | ตัวอักษรเดี่ยว | `char rank = 'A';` |

## 2) แบบฝึกหัด
- **ระดับ 1:** ประกาศตัวแปร 5 ตัวพร้อมค่า
- **ระดับ 2:** สร้างคลาส `PlayerStats` มี field พื้นฐาน
- **ระดับ 3:** อธิบาย primitive vs reference type
