# เดือนที่ 02 — พื้นฐานการเขียนโปรแกรมและตรรกะ

**ช่วงวัน:** Day 031–060 · **บทเรียนละเอียด:** ⏳ (จะเขียนเมื่อจบ Month 1)

## เป้าหมายของเดือน
คิดเป็นขั้นตอนได้ แยกปัญหาใหญ่ออกเป็นฟังก์ชันเล็ก ๆ และใช้ shell script เป็นเครื่องมือฝึกตรรกะ
ก่อนจะย้ายไปภาษา Java ในเดือนถัดไป

## สิ่งที่ต้องมีก่อนเริ่ม
- ผ่านเกณฑ์ Month 1 ครบทุกข้อ
- เขียน script ที่รับ argument และตรวจสอบค่าได้

## หัวข้อหลักในเดือนนี้
1. อินพุต → ประมวลผล → เอาต์พุต และการเขียนผังงาน
2. ตัวแปร ชนิดข้อมูล และการแปลงค่า
3. เงื่อนไขซ้อน เงื่อนไขผสม (AND/OR) และข้อผิดพลาดเชิงตรรกะ
4. ลูป `for`/`while`, ตัวนับ, การออกจากลูป
5. ฟังก์ชัน การส่งค่า และการลดโค้ดซ้ำ
6. อาร์เรย์/ลิสต์ และคู่คีย์-ค่า (map)
7. อ่าน/เขียนไฟล์ข้อมูล (JSON, YAML) และการตรวจสอบข้อมูล
8. ความน่าจะเป็นสำหรับ Loot Table
9. State machine และแนวคิด event/callback
10. การทดสอบโปรแกรมของตัวเองและการดีบักจากอาการ
