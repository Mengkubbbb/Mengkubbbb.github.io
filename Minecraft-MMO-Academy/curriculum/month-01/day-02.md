## A. เป้าหมาย

จบบทนี้คุณจะ:
- จัดการไฟล์ได้เอง: คัดลอก (`cp`), ย้าย/เปลี่ยนชื่อ (`mv`), ลบอย่างระมัดระวัง (`rm`)

- **เขียน shell script ไฟล์แรกที่รันได้จริง** และรับ input จากผู้ใช้ได้

**ผลงานที่ต้องได้:** `~/minecraft-mmo-dev/scripts/first-script.sh` ที่รันได้ (สิทธิ์ 755) + ผลลัพธ์จริงที่บันทึกไว้

## C. แนวคิด

### C.1 ไฟล์ใน Linux มี 2 อย่างเท่านั้น (ในมุมผู้ใช้)

1. **ไฟล์ธรรมดา** เช่น `server.properties`, `start.sh`
2. **โฟลเดอร์** (directory) ซึ่งก็คือไฟล์ชนิดพิเศษที่เก็บรายการไฟล์อื่น

แม้แต่ `world/` ก็เป็นเพียงโฟลเดอร์ที่มีไฟล์จำนวนมากอยู่ข้างใน — ไม่มีเวทมนตร์

### C.2 สิทธิ์ (Permission) คือ "กุญแจ 3 ดอก × คน 3 กลุ่ม"

ลองนึกถึงเซิร์ฟเวอร์ Minecraft ที่มีคำสั่งและ permission node:
`eclipse.admin` ให้ใครทำอะไรได้ — Linux ก็มีแนวคิดเดียวกัน แต่มีแค่ 3 สิทธิ์พื้นฐาน: **อ่าน (r) / เขียน (w) / รัน (x)**

และมี 3 กลุ่มคน: **เจ้าของ (user) / กลุ่ม (group) / คนอื่น (others)**

```text
-rwxr-xr-x
│└┬┘└┬┘└┬┘
│ │  │  └── คนอื่น: r-x (อ่าน+รัน)
│ │  └───── กลุ่ม:   r-x (อ่าน+รัน)
│ └──────── เจ้าของ: rwx (อ่าน+เขียน+รัน)
└────────── ชนิดไฟล์: - = ไฟล์ธรรมดา, d = โฟลเดอร์
```

เขียนเป็นตัวเลขได้ (r=4, w=2, x=1):

| สิทธิ์ | ตัวเลข | ความหมายที่ใช้จริง |
| --- | --- | --- |
| `rwxr-xr-x` | **755** | เจ้าของแก้ได้ คนอื่นรัน/อ่านได้ → **ไฟล์ script ทั่วไป** |
| `rw-r--r--` | 644 | เจ้าของแก้ได้ คนอื่นอ่านได้อย่างเดียว → **ไฟล์ข้อมูล/ตั้งค่า** |
| `rwx------` | 700 | เข้าได้เฉพาะเจ้าของ → **ไฟล์ที่มีข้อมูลลับ** |
| `rwxrwxrwx` | 777 | ทุกคนทำได้ทุกอย่าง → ⚠️ **ห้ามใช้กับ script/โฟลเดอร์ที่เราดูแล** |

> ⚠️ **ทำไม 777 อันตราย:** ใครก็ตามในเครื่อง (หรือโปรแกรมที่ถูกเจาะ) สามารถ **แก้ script ของเราได้**
> เมื่อ script ถูกแก้ ก็รันโค้ดอะไรก็ได้ในนามของเรา — สำหรับเซิร์ฟเวอร์ที่เปิดให้คนอื่นเข้า นี่คือช่องโหว่จริง

### C.3 ไฟล์ที่ชื่อขึ้นต้นด้วย `.` คือไฟล์ซ่อน

เช่น `.bashrc` `ls` เฉย ๆ ไม่แสดง ต้องใช้ `ls -la` (ตัว `a` = all) ไฟล์เหล่านี้มักเป็นไฟล์ตั้งค่าของโปรแกรม — **แตะได้ แต่ต้องรู้ว่ากำลังทำอะไร**

### C.4 Script คืออะไร

**Script** = ไฟล์ข้อความที่มีคำสั่งให้ shell รันทีละบรรทัด

เทียบกับเกม: ถ้า `/give` คือคำสั่งเดี่ยว ๆ **script ก็คือ "มาโคร"** ที่รวบหลายคำสั่งไว้ในไฟล์เดียว แล้วสั่งให้ทำทั้งหมดด้วยคำสั่งเดียว

บรรทัดแรกของ script มีความหมายพิเศษ เรียกว่า **shebang**:

```bash
#!/usr/bin/env bash
```

แปลว่า: "ให้ใช้โปรแกรม `bash` ในเครื่องนี้รันไฟล์นี้" — ถ้าไม่มีบรรทัดนี้ ระบบอาจใช้ shell อื่น (เช่น `sh`) ที่ไม่รู้จักคำสั่งที่เราเขียน

## D. ตัวอย่าง

### D.1 ทดลองสิทธิ์ (สร้างไฟล์ทดลองใน `lab/`)

```bash
cd ~/minecraft-mmo-dev/lab
echo "hello" > perm-test.sh
ls -l perm-test.sh          # สังเกตว่าไม่มี x (รันไม่ได้)
chmod +x perm-test.sh
ls -l perm-test.sh          # มี x เพิ่มแล้ว
```

**ผลลัพธ์ที่คาดหวัง (ก่อน → หลัง):**
```text
-rw-r--r-- 1 you you 6 ... perm-test.sh
-rwxr-xr-x 1 you you 6 ... perm-test.sh
```

### D.2 ลองรันไฟล์ที่ไม่ใช่ script

```bash
./perm-test.sh
```

จะได้ข้อความแปลก ๆ เช่น `hello: command not found` — เพราะไฟล์นี้เป็น "ข้อความ" ที่ไม่มี shebang
ระบบจึงพยายามรันมันด้วย shell และเข้าใจผิดว่า `hello` คือชื่อคำสั่ง
**บทเรียน:** ไฟล์ script ต้องมี shebang และมีสิทธิ์ `x`

### D.3 ลบอย่างมีมารยาท

```bash
cd ~/minecraft-mmo-dev/lab
ls -la perm-test.sh        # ตรวจให้แน่ใจก่อนลบ (นิสัยนี้ต้องติดตัว)
rm perm-test.sh
ls -la
```

> ⚠️ `rm` ไม่มีถังขยะ — ลบแล้วจบ อย่าลบไฟล์ด้วย path ที่พิมพ์จากความจำ ให้ใช้ `ls` ยืนยันก่อนทุกครั้ง

## E. ลงมือทำ

### ขั้นที่ 1: สร้างไฟล์ script แรก

เปิด editor ที่ถนัด (ตอนนี้ใช้ `nano` ได้ — จะเปลี่ยนเป็น VS Code ใน Day 04)

```bash
cd ~/minecraft-mmo-dev/scripts
nano first-script.sh
```

พิมพ์เนื้อหาด้านล่างนี้ (พิมพ์เองทีละบรรทัด ไม่ต้องก็อปวาง):

```bash
#!/usr/bin/env bash
# first-script.sh — script แรกของหลักสูตร Minecraft MMO RPG Academy
# หน้าที่: ทักทายและแสดงข้อมูลพื้นฐานของเครื่อง

echo "========================================"
echo " Eclipse MMO RPG Academy — Day 02"
echo "========================================"
echo "สวัสดี $(whoami)"
echo "เครื่องนี้คือ: $(hostname)"
echo "ระบบปฏิบัติการ: $(uname -s) $(uname -r)"
echo "ตอนนี้เวลา: $(date '+%Y-%m-%d %H:%M:%S')"
echo "โฟลเดอร์ปัจจุบัน: $(pwd)"
echo "========================================"
```

บันทึกและออกจาก nano: กด `Ctrl + O` แล้ว `Enter` จากนั้น `Ctrl + X`

### ขั้นที่ 2: ให้สิทธิ์รัน + ทดสอบ

```bash
chmod 755 first-script.sh
ls -l first-script.sh
./first-script.sh
```

**ผลลัพธ์ที่คาดหวัง** (ตัวอย่าง — ค่าจริงของคุณจะต่างกัน):
```text
========================================
 Eclipse MMO RPG Academy — Day 02
========================================
สวัสดี mengkub
เครื่องนี้คือ: cachyos-pc
ระบบปฏิบัติการ: Linux 6.x.x
ตอนนี้เวลา: 2026-10-27 20:41:02
โฟลเดอร์ปัจจุบัน: /home/mengkub/minecraft-mmo-dev/scripts
========================================
```

### ขั้นที่ 3: รันจากที่อื่นด้วยพาธแบบเต็ม (ทดสอบว่า script ไม่ผูกกับที่เดียว)

```bash
cd ~
~/minecraft-mmo-dev/scripts/first-script.sh
```

### ขั้นที่ 4: ทำให้ script รับ argument (ฝึก Independent Practice)

แก้ไฟล์ `first-script.sh` ให้รับ argument ตัวแรกเป็นชื่อผู้เล่น:

```bash
#!/usr/bin/env bash
# first-script.sh — v2: รับชื่อผู้เล่นเป็น argument
# ใช้: ./first-script.sh <ชื่อผู้เล่น>

PLAYER_NAME="$1"        # $1 = argument ตัวแรกที่พิมพ์ต่อท้ายคำสั่ง

if [ -z "$PLAYER_NAME" ]; then      # -z = "ข้อความว่างหรือไม่"
    echo "วิธีใช้: $0 <ชื่อผู้เล่น>"
    echo "ตัวอย่าง: $0 Somchai"
    exit 1                          # ออกจาก script ด้วยรหัส 1 = เกิดข้อผิดพลาด
fi

echo "ยินดีต้อนรับสู่ Eclipse MMO RPG, $PLAYER_NAME!"
echo "บันทึกเวลาเข้าเล่น: $(date '+%Y-%m-%d %H:%M:%S')"
```

ทดสอบทั้งกรณีปกติและกรณีผิด:

```bash
./first-script.sh Somchai     # ควรได้ข้อความต้อนรับ
./first-script.sh             # ควรได้ข้อความวิธีใช้ และ exit code = 1
echo "exit code ล่าสุด: $?"   # $? = ผลลัพธ์ของคำสั่งล่าสุด (0 = สำเร็จ)
```

### ขั้นที่ 5: บันทึกหลักฐาน

```bash
{
  echo "### Day 02 — first-script.sh"
  echo "คำสั่ง: ./first-script.sh Somchai"
  ./first-script.sh Somchai
  echo
  echo "คำสั่ง: ./first-script.sh (ไม่ใส่อะไร)"
  ./first-script.sh
} > ~/minecraft-mmo-dev/notes/day02-output.txt
cat ~/minecraft-mmo-dev/notes/day02-output.txt
```

### G.1 พื้นฐาน

เขียน script `~/minecraft-mmo-dev/scripts/hello-academy.sh` ที่:
1. มี shebang

**สิ่งที่ต้องส่ง:** เนื้อหาไฟล์ + ผลลัพธ์การรัน + ผล `ls -l hello-academy.sh`

### G.2 ประยุกต์

เขียน script `~/minecraft-mmo-dev/scripts/player-info.sh` ที่รับ argument 2 ตัว: ชื่อผู้เล่น และระดับการเล่น (เลเวล)
ให้:
- ถ้าไม่ใส่อะไรครบ 2 ตัว → พิมพ์วิธีใช้แล้ว `exit 1`
- ถ้าใส่ครบ → พิมพ์ข้อความว่า `<ชื่อ> เลเวล <เลเวล>` และคำนวณ "เลือดสูงสุด" ด้วยสูตร `100 + (เลเวล × 10)` แล้วแสดงผล

**ตัวอย่างผลลัพธ์ที่ต้องการ:**
```text

```

**คำใบ้ (ถ้าติด):** การคำนวณใน bash เขียนแบบนี้ได้ `$(( 100 + $LEVEL * 10 ))`

**สิ่งที่ต้องส่ง:** เนื้อหาไฟล์ + ผลลัพธ์ 2 กรณี (ใส่ครบ/ไม่ครบ)

## K. Troubleshooting

| อาการ | สาเหตุ | วิธีตรวจสอบ | วิธีแก้ |
| --- | --- | --- | --- |
| `bash: ./first-script.sh: Permission denied` | ไฟล์ไม่มีสิทธิ์รัน | `ls -l first-script.sh` | `chmod 755 first-script.sh` |
| `bash: ./first-script.sh: /usr/bin/env: bad interpreter` | ไฟล์ถูกบันทึกแบบ CRLF (Windows) | `file first-script.sh` (ขึ้น `with CRLF line terminators`) | `sed -i 's/\r$//' first-script.sh` |
| `command not found` ทั้งที่พิมพ์ถูก | ไฟล์ไม่มี shebang หรือไม่ได้รันด้วย `./` | `head -1 first-script.sh` | เพิ่ม shebang แล้วรันด้วย `./` |
| พิมพ์ `./file` แล้วได้ `No such file or directory` | พาธ/ชื่อไฟล์ผิด หรืออยู่ผิดโฟลเดอร์ | `pwd` + `ls` | `cd` ให้ถูกแล้วลองใหม่ |
| ข้อความไทยเพี้ยน | locale | `locale` | `export LANG=C.UTF-8` ใน `~/.bashrc` |
| `$?` ได้ค่าที่ไม่คาดคิด | ถูกสั่งทับด้วยคำสั่งอื่น (เช่น `echo`) | เรียกทันทีหลังคำสั่งที่สนใจ | เก็บค่าก่อน: `STATUS=$?` |

## L. สรุป

- ไฟล์ใน Linux มีสิทธิ์ 3 อย่าง (r/w/x) × 3 กลุ่ม (เจ้าของ/กลุ่ม/คนอื่น) = เขียนเป็นตัวเลข 3 หลักได้
- script ต้องมี **shebang** และ **สิทธิ์ x** จึงจะรันได้
- `chmod 755` คือค่าเริ่มต้นที่ปลอดภัยสำหรับ script, ไฟล์ข้อมูลใช้ 644 และหลีกเลี่ยง 777
- script รับ input ได้ผ่าน `$1`, `$2` และตรวจสอบได้ด้วย `[ -z "$1" ]`
- `$?` บอกผลลัพธ์ของคำสั่งล่าสุด — ใช้ตรวจว่า script สำเร็จหรือไม่

**บทต่อไป (Day 03):** เราจะทำให้ Terminal "เร็วขึ้น" ด้วย alias, หาไฟล์ด้วย `find`/`grep`
และเข้าใจ `PATH` ซึ่งเป็นสาเหตุอันดับหนึ่งที่ทำให้คำสั่ง `java`, `gradle` ใช้ไม่ได้แม้ติดตั้งแล้ว
