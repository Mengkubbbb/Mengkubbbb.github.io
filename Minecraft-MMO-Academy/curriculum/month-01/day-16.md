# Day 16: SSH, Key-based Auth & เข้าใจ Remote Server

> เป้าหมาย: เข้าใจการเชื่อมต่อ SSH แบบปลอดภัยด้วยคีย์ (ไม่ใช้รหัสผ่าน)
> เวลาที่ใช้: ~1–2 ชั่วโมง | ระดับ: เริ่มต้น

## 1) แนวคิด
- **SSH** = Secure Shell สำหรับควบคุมเซิร์ฟเวอร์ระยะไกล
- **Public/Private key** = ใช้คีย์แทนรหัสผ่าน ปลอดภัยกว่า
- **~/.ssh/** = เก็บคีย์ของผู้ใช้
- **authorized_keys** = คีย์ที่อนุญาตให้เข้าเครื่องเป้าหมาย

## 2) ลงมือทำ (จำลองในเครื่อง)

### 2.1 สร้าง SSH key
```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
# กด Enter ผ่านได้ (หรือใส่ passphrase ก็ได้)
```

### 2.2 ดูคีย์
```bash
ls -la ~/.ssh/
cat ~/.ssh/id_ed25519.pub
```

### 2.3 แนวทางใช้งานจริง
- คัดลอก public key ไปใส่ `~/.ssh/authorized_keys` บนเซิร์ฟเวอร์
- ใช้ `ssh user@IP` โดยไม่ต้องใส่รหัสผ่าน
- **ห้าม** คัดลอก private key (`id_ed25519`) ออกนอกเครื่องเด็ดขาด

## 3) ความปลอดภัยพื้นฐาน
- ปิด PasswordAuthentication ถ้าใช้ key อย่างเดียว
- ใช้ user ที่ไม่ใช่ root สำหรับงานประจำ
- เปลี่ยนพอร์ต SSH ได้ (ขั้นสูง) แต่ไม่จำเป็นสำหรับเริ่มต้น

## 4) แบบฝึกหัด
- **ระดับ 1:** สร้าง ed25519 key และดูไฟล์
- **ระดับ 2:** อธิบายความแตกต่าง public vs private
- **ระดับ 3:** ทำ security checklist สั้นๆ สำหรับ SSH

## 5) Checklist

- [ ] รู้ข้อห้ามเรื่อง private key
