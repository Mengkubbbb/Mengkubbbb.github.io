## D. ลงมือทำ: รวมเป็นชุดเครื่องมือ `mmo`

### ขั้นที่ 1: สร้างตัวสั่งงานกลาง

```bash
cd ~/minecraft-mmo-dev/scripts
cat > mmo <<'EOF'
#!/usr/bin/env bash
# mmo — ตัวสั่งงานกลางของโปรเจกต์ (เรียก script อื่นให้)
set -uo pipefail

SCRIPT_DIR="$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)"
source "${SCRIPT_DIR}/lib.sh"

readonly VERSION="0.1.0"

usage() {
  cat <<HELP
mmo $VERSION — เครื่องมือจัดการโปรเจกต์ Eclipse MMO RPG

วิธีใช้: mmo <คำสั่ง> [อาร์กิวเมนต์...]

คำสั่ง:
  info                     ข้อมูลเครื่องและเวอร์ชัน Java
  worlds [--dry-run] ...    สร้างโฟลเดอร์โลก
  perms                     ตั้งสิทธิ์มาตรฐาน
  scan <log>               สรุป error/warn จาก log
  help                     แสดงข้อความนี้
HELP
}

cmd="${1:-help}"; shift || true
case "$cmd" in
  info)   exec "${SCRIPT_DIR}/server-info.sh" "$@" ;;
  worlds) exec "${SCRIPT_DIR}/create-worlds.sh" "$@" ;;
  perms)  exec "${SCRIPT_DIR}/secure-permissions.sh" "$@" ;;
  scan)   exec "${SCRIPT_DIR}/scan-log.sh" "$@" ;;
  help|-h|--help) usage; exit 0 ;;
  *) usage >&2; die "ไม่รู้จักคำสั่ง: $cmd" 2 ;;
esac
EOF
chmod 755 mmo && bash -n mmo && echo "syntax OK"
```

### ขั้นที่ 2: ติดตั้งให้เรียกได้จากทุกที่ (ไม่ต้องใช้ sudo)

```bash
mkdir -p ~/.local/bin
ln -sfn ~/minecraft-mmo-dev/scripts/mmo ~/.local/bin/mmo
grep -q 'HOME/.local/bin' ~/.bashrc || echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
export PATH="$HOME/.local/bin:$PATH"
mmo help | head -8
```

> 💡 การใช้ `~/.local/bin` คือวิธีติดตั้งเครื่องมือส่วนตัวที่ปลอดภัยกว่า `sudo cp /usr/local/bin` เพราะไม่ต้องใช้สิทธิ์ root และไม่กระทบผู้ใช้อื่น

### ขั้นที่ 3: รันทดสอบรวมทั้งชุด

```bash
cd ~/minecraft-mmo-dev/scripts
echo "=== 1) info ===";              ./mmo info 2>/dev/null | head -5
```

## E. แบบทดสอบ 20 ข้อ (ปิดเอกสารก่อนทำ)

> ตอบในหัวหรือเขียนลง `notes/week-02-review.md` แล้วตรวจกับเฉลยท้ายบท

1. `X = 1` ใน bash เกิดอะไรขึ้น
2. ตัวแปรที่ค่ามีช่องว่าง ต้องอ้างอย่างไร
3. `$#` เก็บอะไร
4. `"$@"` ต่างจาก `$@` อย่างไร
5. `${1:-default}` ทำอะไร
6. `[ ]` กับ `[[ ]]` ต่างกันอย่างน้อย 2 ข้อ
7. ตัวดำเนินการเปรียบเทียบ **ตัวเลข** มีอะไรบ้าง (อย่างน้อย 4)
8. ทำไม `[[ "10" < "9" ]]` เป็นจริง
9. `(( 08 + 1 ))` เกิดอะไร และแก้อย่างไร
10. `case` ต้องมีกรณี `*)` เพราะอะไร
11. คำนวณทศนิยมใน bash ต้องใช้เครื่องมืออะไร
12. `for` มี 3 แบบ อะไรบ้าง
13. ทำไมไม่ควรใช้ `for line in $(cat file)`
14. `IFS= read -r` แต่ละส่วนทำอะไร
15. `break` กับ `continue` ต่างกันอย่างไร
16. `return` กับ `exit` ต่างกันอย่างไร (ในฟังก์ชัน)
17. จะคืน "ข้อความ" จากฟังก์ชันได้อย่างไร
18. `local` มีไว้ทำอะไร
19. `uniq -c` ต้องมีคำสั่งใดนำหน้า เพราะอะไร
20. `r` กับ `x` บนโฟลเดอร์ต่างกันอย่างไร

**เกณฑ์:** ≥ 16/20 = พร้อมไปสัปดาห์ 3 · 12–15 = ทบทวนหัวข้อที่พลาดก่อน · < 12 = เรียนซ้ำ Day 08–13 อีกครั้ง (ไม่ใช่ความล้มเหลว — เป็นการลงทุนที่คุ้ม)

## F. เฉลยย่อ (ตรวจหลังตอบเองแล้วเท่านั้น)

1. bash พยายามรันคำสั่งชื่อ `X` พร้อมอาร์กิวเมนต์ `=` และ `1` → `command not found`
2. ใส่เครื่องหมายคำพูดคู่: `"$var"`
3. จำนวนอาร์กิวเมนต์ที่ส่งเข้ามา
4. `"$@"` รักษาขอบเขตของแต่ละอาร์กิวเมนต์ (ชื่อมีช่องว่างไม่แตก); `$@` แตกคำ
5. ใช้ `$1` ถ้ามีค่า ไม่งั้นใช้ `default`
6. `[[ ]]` เป็น keyword ของ bash: ปลอดภัยกับค่าว่าง, รองรับ `=~` regex, ใช้ `&&`/`||` ในวงเล็บได้; `[ ]` เป็นคำสั่งภายนอก (POSIX)
7. `-eq -ne -lt -le -gt -ge`
8. เพราะ `<` ใน `[[ ]]` เทียบตามลำดับตัวอักษร (`1` < `9`) ไม่ใช่ค่าตัวเลข
9. bash ตีความ `08` เป็นเลขฐานแปด → error; แก้ด้วย `10#08`
10. เพื่อจับค่าที่ไม่รู้จัก/พิมพ์ผิด ไม่ให้ผ่านเงียบ ๆ
11. `awk` (หรือ `bc`) — bash ทำทศนิยมไม่ได้
12. รายการค่า, array (`"${arr[@]}"`), นับจำนวน (`for (( ))`)
13. แตกคำตามช่องว่าง, เปลือง memory, ไม่รองรับบรรทัดสุดท้ายไม่มี newline
14. `IFS=` ไม่ตัดช่องว่างหัวท้าย, `read -r` ไม่ตีความ backslash
15. `break` ออกจากลูป, `continue` ข้ามไปรอบถัดไป
16. `return` ออกจากฟังก์ชันพร้อม exit code (0–255); `exit` จบทั้ง script
17. `echo "ค่า"` แล้วผู้เรียกใช้ `value="$(f)"`
18. จำกัดขอบเขตตัวแปรให้อยู่แค่ในฟังก์ชัน (กันทับตัวแปรนอก)
19. `sort` — เพราะ `uniq` นับได้เฉพาะค่าที่อยู่ติดกัน
20. `r` = ดูรายชื่อไฟล์ในโฟลเดอร์; `x` = เข้าไป/เข้าถึงไฟล์ข้างในได้

## K. Troubleshooting

| อาการ | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| `mmo: command not found` | `~/.local/bin` ไม่อยู่ใน PATH | `export PATH="$HOME/.local/bin:$PATH"` และเพิ่มใน `~/.bashrc` |
| `mmo` เรียก script แล้ว `No such file` | symlink ชี้ผิด/ไฟล์ไม่มี | `ls -l ~/.local/bin/mmo` แล้วสร้าง symlink ใหม่ |
| `exec: ... Permission denied` | script เป้าหมายไม่มี `x` | `chmod 755 scripts/*.sh` |
| `mmo scan` ไม่แสดงอะไร | log ไม่มี error จริง | ลองกับ `sample.log` ก่อน |
| `bash: ./mmo: bad interpreter` | บรรทัดแรก (`#!`) ผิดหรือมี CRLF | เขียนใหม่ด้วย `#!/usr/bin/env bash` และแปลง LF |
| แบบทดสอบได้ < 12 | ยังไม่แน่น (ปกติของมือใหม่) | เรียน Day 08–13 ซ้ำเฉพาะหัวข้อที่พลาด ไม่ต้องเริ่มทั้งเดือน |
| Git มีไฟล์แปลกปลอมเต็มไปหมด | ไม่มี `.gitignore` | เพิ่ม `logs/`, `*.log`, `world/`, `build/` |
