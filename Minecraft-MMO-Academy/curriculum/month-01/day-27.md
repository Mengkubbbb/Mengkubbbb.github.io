# Day 27: Security เบื้องต้น (SSH, Files, OP)

> เป้าหมาย: รู้จุดเสี่ยงและลดความเสี่ยงพื้นฐาน
> เวลาที่ใช้: ~1–2 ชั่วโมง | ระดับ: กลาง

## 1) Checklist ความปลอดภัย
- [ ] ใช้ SSH key แทน password
- [ ] มี user ปกติ ไม่ใช้ root ในการรันเซิร์ฟเวอร์
- [ ] จำกัด OP ให้แค่คนที่จำเป็น
- [ ] สำรองอย่างสม่ำเสมอ
- [ ] ไม่แชร์ private key
- [ ] ปิดพอร์ตที่ไม่จำเป็น

## 2) แบบฝึกหัด
- **ระดับ 1:** ทำ security checklist ครบ
- **ระดับ 2:** หาจุดเสี่ยง 3 จุดใน setup ปัจจุบัน
- **ระดับ 3:** เขียนแผนแก้ไขแต่ละจุด

## 3) Checklist
- [ ] เข้าใจความแตกต่าง user vs OP
- [ ] รู้ข้อห้ามหลัก
- [ ] มีสติเรื่องสิทธิ์

## สรุป
ปลอดภัยเริ่มจากนิสัย ไม่ใช่แค่เครื่องมือ
