# เดือนที่ 01 — Linux, Terminal, ระบบไฟล์ และเครื่องมือพัฒนา

**ช่วงวัน:** Day 001–030 · **บทเรียนละเอียด:** Day 01–07 ✅ · Day 08–30 ⏳ (จะเขียนเมื่อเรียนถึง)

## เป้าหมายของเดือน
ใช้ Terminal ได้อย่างมั่นใจ เข้าใจว่าระบบไฟล์และสิทธิ์ทำงานอย่างไร เขียน shell script ที่รับ input/ตรวจสอบค่าได้
และมีเครื่องมือพร้อมสำหรับเขียน Java (VS Code + JDK 25 + Git)

## สิ่งที่ต้องมีก่อนเริ่ม
- คอมที่ลง CachyOS และเปิด Terminal ได้
- พื้นที่ว่างในดิสก์อย่างน้อย 10 GB (สำหรับ JDK, Gradle, เซิร์ฟเวอร์ทดสอบ)
- เวลาวันละ 2–3 ชั่วโมง

## หัวข้อหลักในเดือนนี้
1. โครงสร้างระบบไฟล์ Linux และคำสั่งที่ใช้ทุกวัน (`ls`, `cd`, `cp`, `mv`, `rm`, `find`)
2. สิทธิ์ไฟล์ (`chmod`, `chown`, `umask`) และทำไม script ต้องมีสิทธิ์รัน
3. Shell script: ตัวแปร, อาร์กิวเมนต์, เงื่อนไข, ลูป, ฟังก์ชัน
4. ท่อคำสั่งและตัวกรองข้อความ (`|`, `grep`, `sed`, `awk`, `sort`, `uniq`)
5. จัดการ log, ตรวจสุขภาพเครื่อง, ดูโปรเซส
6. เครือข่ายเบื้องต้น: IP, port, `curl`, `ping`
7. Git พื้นฐานสำหรับเก็บงานทุกวัน
8. Editor (VS Code) และส่วนขยายที่จำเป็น + JDK 25

## โปรเจกต์ประจำเดือน
`projects/01-linux-lab/` — โครงโฟลเดอร์เซิร์ฟเวอร์ + script ที่ใช้งานได้จริง 4 ไฟล์:
`first-script.sh`, `server-check.sh`, `backup.sh`, `server-start.sh`

- [ ] ตอบได้ว่า `java -version` ที่เครื่องคือเวอร์ชันอะไร และเพราะอะไรหลักสูตรใช้ JDK 25
