# เดือนที่ 07 — บริหารเซิร์ฟเวอร์, Plugin Management และ Resource Pack

**ช่วงวัน:** Day 181–210 · **บทเรียนละเอียด:** ⏳

## เป้าหมายของเดือน
ติดตั้งเซิร์ฟเวอร์ Paper 26.3 ได้เองจากศูนย์ ดูแล/สำรอง/กู้คืนข้อมูลได้
และสร้าง Resource Pack ที่มีไอเทมและ HUD ของตัวเอง พร้อมบันทึกข้อจำกัดจริงของไคลเอนต์ Vanilla

## สิ่งที่ต้องมีก่อนเริ่ม
- ปลั๊กอิน v2 ทำงานได้
- เข้าใจ event/command/config

## หัวข้อหลักในเดือนนี้
1. ติดตั้ง Paper 26.3 (build STABLE) + ตั้ง RAM/JVM flags ที่เหมาะสม
2. `server.properties` ทีละค่าที่สำคัญ, EULA, whitelist, online-mode
3. เปิด-ปิดเซิร์ฟเวอร์อย่างปลอดภัย + console commands
4. จัดการปลั๊กอิน: วิธีเลือก ติดตั้ง อัปเดต ถอน และการตรวจ dependency
5. LuckPerms: โครงกลุ่มสิทธิ์ที่ใช้จริง
6. ปลั๊กอินป้องกันโลก/ย้อนประวัติ (CoreProtect/WorldGuard) — ทดสอบจริง 1 เคส
7. สำรองข้อมูลอัตโนมัติ + **ทดสอบกู้คืนจริง** (ไม่ใช่แค่มีไฟล์สำรอง)
8. อ่าน log/crash report และหาสาเหตุ
9. ประสิทธิภาพเบื้องต้น: TPS, timings/spark
10. ความปลอดภัยเครือข่าย: firewall, port, ห้ามเปิด RCON สาธารณะ
11. Resource Pack: โครงสร้าง, `pack.mcmeta`, `pack_format`
12. Texture + Custom Model Data + Blockbench + HUD
13. การแจก pack (URL + SHA1) และทดสอบกับไคลเอนต์หลายเวอร์ชัน
14. ประเมิน MCGUI / RP Engine ตามข้อจำกัดจริง + บันทึกเรื่องกล้อง Isometric

## โปรเจกต์ประจำเดือน
เซิร์ฟเวอร์ทดสอบที่ตั้งค่าแล้ว + Resource Pack ที่มีไอเทมของเรา 1 ชิ้น + `docs/camera-limits.md`

## เกณฑ์ผ่านก่อนขึ้น Month 8
- [ ] เพื่อน 1 คนเข้าเซิร์ฟเวอร์ทดสอบได้ (ผ่าน whitelist) และเห็น resource pack
- [ ] กู้คืนจากไฟล์สำรองได้จริง 1 ครั้ง พร้อมบันทึกเวลา
- [ ] อธิบายได้ว่า `pack_format` ต้องตรงกับอะไร และถ้าไม่ตรงจะเกิดอะไร
- [ ] ระบุได้ว่ากล้อง Isometric ทำได้/ไม่ได้แค่ไหนบนไคลเอนต์ Vanilla พร้อมหลักฐานจากการทดลอง

## คำเตือนของเดือนนี้
> ⚠️ อย่าเปิดเซิร์ฟเวอร์ให้คนนอกเข้าโดยไม่ตั้ง whitelist และไม่สำรองข้อมูลก่อน
> ⚠️ Resource pack ที่ผิด `pack_format` จะทำให้ผู้เล่นเห็น pack เสีย — ต้องทดสอบกับเวอร์ชันไคลเอนต์จริงเสมอ
