# เดือนที่ 09 — Combat, Skills, Magic, Classes และ Animation

**ช่วงวัน:** Day 241–270 · **บทเรียนละเอียด:** ⏳

## เป้าหมายของเดือน
มีระบบต่อสู้ที่คำนวณได้ ทดสอบได้ และปรับสมดุลได้ด้วยข้อมูล พร้อมเวทมนตร์ ธาตุ และคลาส
และเข้าใจข้อจำกัดจริงของการทำแอนิเมชัน/HUD บนไคลเอนต์ Vanilla

## สิ่งที่ต้องมีก่อนเริ่ม
- Character System v1 (Month 8)
- เขียน unit test ได้ (Month 4)

## หัวข้อหลักในเดือนนี้
1. ลำดับการคำนวณดาเมจ (base → multiplier → defense → crit → final)
2. Damage event + การไม่ให้ดาเมจซ้ำซ้อน
3. คูลดาวน์/Global cooldown และการแสดงผล
4. Status effect (burn/poison/slow) พร้อมเวลาและ stack
5. Skill Registry + การเพิ่มสกิลใหม่โดยไม่แก้โค้ดหลัก
6. Targeting, range, line of sight
7. Mana/resource และการฟื้นฟู
8. ระบบธาตุ + Elemental Reaction
9. Classes และสกิลประจำคลาส + การรีสกิล
10. Combo, boss phase/telegraph
11. ปรับสมดุลด้วยข้อมูลจริง (ไม่ใช่ความรู้สึก)
12. HUD (เลือด/มานา/สกิล), damage indicator, emote
13. แอนิเมชัน: ทำได้แค่ไหนบน Vanilla, ทางเลือก client mod
14. ทดลองกล้อง Isometric รอบที่สอง + บันทึกผล
