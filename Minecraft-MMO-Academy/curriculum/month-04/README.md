# เดือนที่ 04 — OOP, Collections, Error Handling และ Testing

**ช่วงวัน:** Day 091–120 · **บทเรียนละเอียด:** ⏳

## เป้าหมายของเดือน
ออกแบบคลาสที่ขยายต่อได้จริง ใช้ interface/composition ให้ถูกงาน ใช้ collection เลือกถูกชนิด
จัดการข้อผิดพลาดอย่างเป็นระบบ และเขียน unit test ของตัวเองได้

## สิ่งที่ต้องมีก่อนเริ่ม
- ผ่านเกณฑ์ Month 3
- เขียนคลาสที่มี constructor + เมธอดคำนวณได้

## หัวข้อหลักในเดือนนี้
1. OOP ในมุมของเกม: ไอเทม/ตัวละคร/สกิล ควรเป็นคลาสอะไร
2. Inheritance และข้อควรระวัง (เมื่อไรไม่ควรสืบทอด)
3. Composition และการประกอบระบบ
4. Interface / abstract class และการออกแบบสัญญา
5. Polymorphism ผ่านระบบสกิล
6. Collections: List, Set, Map — เลือกตามงาน
7. Generics, `record`, `Optional`
8. Lambda, functional interface, Stream เบื้องต้น
9. Custom exception และ logging
10. JUnit 5 และการเขียนเทสต์สูตรคำนวณ
11. Design pattern ที่ใช้จริงในปลั๊กอิน: Singleton, Factory, Registry, Strategy
12. แนวคิด Observer/EventBus (ปูทางไป Paper Event ใน Month 6)
