# Checklist: Plugin Load & Commands (ปลั๊กอินโหลดและทำงาน)

**ใช้เมื่อ:** ทุกครั้งที่ build ปลั๊กอินใหม่และติดตั้งลงเซิร์ฟเวอร์ทดสอบ
**คัดลอกไปไว้:** `docs/test-runs/YYYY-MM-DD-plugin-load.md`

| # | รายการตรวจ | ผ่าน? | หลักฐาน |
| --- | --- | --- | --- |
| 1 | `./gradlew build` ผ่าน ไม่มี error | ☐ | ผลลัพธ์: |
| 2 | ได้ไฟล์ `.jar` ใหม่ใน `build/libs/` (ตรวจเวลาแก้ไข) | ☐ | `ls -l build/libs/` → |
| 3 | คัดลอก `.jar` ไปที่ `plugins/` แล้ว (ไม่มีไฟล์เก่าค้าง) | ☐ | `ls -l plugins/` → |
| 4 | รีสตาร์ทเซิร์ฟเวอร์ (ไม่ใช้ `/reload`) | ☐ | — |
| 5 | log แสดงว่าปลั๊กอิน enabled พร้อมเวอร์ชันถูกต้อง | ☐ | log: |
| 6 | `/plugins` เห็นชื่อปลั๊กอินเป็นสีเขียว | ☐ | ผลลัพธ์: |
| 7 | คำสั่งหลักของปลั๊กอินทำงานได้ | ☐ | คำสั่ง: |
| 8 | ใช้คำสั่งผิดรูปแบบ → ได้ข้อความช่วยเหลือ ไม่ใช่ error | ☐ | ผลลัพธ์: |
| 9 | Tab-completion ทำงาน | ☐ | ผลลัพธ์: |
| 10 | ผู้เล่นไม่มีสิทธิ์ → ถูกปฏิเสธพร้อมข้อความ | ☐ | ผู้เล่น/คำสั่ง: |
| 11 | ไม่มี `NullPointerException` หรือ stack trace ใน log | ☐ | log: |
| 12 | ปิดเซิร์ฟเวอร์แล้วไม่มี error ตอน `onDisable` | ☐ | log: |

**ทดสอบกับผู้เล่นจริง:** ☐ ผู้เล่น 1 คน ☐ ผู้เล่น 2 คน (แยกบัญชี) ☐ ยังไม่ได้ทดสอบ

**สรุปผล:** ☐ ผ่านทั้งหมด ☐ ผ่านบางส่วน ☐ ไม่ผ่าน
