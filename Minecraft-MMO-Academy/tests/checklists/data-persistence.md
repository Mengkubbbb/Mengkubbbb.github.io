# Checklist: Data Persistence (ข้อมูลไม่หาย)

**ใช้เมื่อ:** ทุกครั้งที่แตะระบบข้อมูลผู้เล่น ไอเทม เงิน เลเวล เควส
**คัดลอกไปไว้:** `docs/test-runs/YYYY-MM-DD-persistence.md`

> ⚠️ ทดสอบนี้เป็นหัวใจของ MMO — ถ้าข้อมูลหาย ผู้เล่นจะไม่กลับมา

| # | ขั้นตอนทดสอบ | ผลที่คาดหวัง | ผ่าน? | หลักฐาน |
| --- | --- | --- | --- | --- |
| 1 | ผู้เล่นใหม่เข้าเซิร์ฟเวอร์ครั้งแรก | มีแถวข้อมูลถูกสร้าง | ☐ | query: |
| 2 | เก็บเลเวล/EXP แล้วตรวจใน DB | ค่าตรงกับที่เห็นในเกม | ☐ | query + ค่าในเกม |
| 3 | ได้ไอเทมแล้วตรวจการบันทึก | ไอเทมถูกบันทึกพร้อมค่าครบ | ☐ | query: |
| 4 | ได้เงิน/ใช้เงินแล้วตรวจยอด | ยอดตรง ไม่มีเศษผิดปกติ | ☐ | query: |
| 5 | ออกจากเกมแล้วเข้าใหม่ | ค่าทั้งหมดกลับมาครบ | ☐ | บันทึก: |
| 6 | รีสตาร์ทเซิร์ฟเวอร์ด้วย `stop` แล้วเข้าใหม่ | ข้อมูลครบ | ☐ | บันทึก: |
| 7 | **ปิดเซิร์ฟเวอร์แบบไม่ปกติ** (`kill -9`) แล้วเข้าใหม่ | ข้อมูลงวดล่าสุดไม่หาย (ตามที่ออกแบบ) | ☐ | บันทึก: |
| 8 | ผู้เล่น 2 คนเข้าเล่นพร้อมกัน | ข้อมูลไม่ทับกัน | ☐ | บันทึก: |
| 9 | ผู้เล่น 2 คนใช้คำสั่งเดียวกันพร้อมกัน | ไม่มีค่าผิดปกติ (race condition) | ☐ | บันทึก: |
| 10 | ตรวจว่าไม่มี query ทำงานหนักบน main thread | ไม่มีการเตือนใน log / TPS ไม่ตก | ☐ | ผลวัด: |

**ก่อนทดสอบต้องมี:** ☐ ไฟล์สำรองล่าสุด ☐ รู้คำสั่ง query ตรวจข้อมูล ☐ รู้วิธีย้อนกลับ (restore)

**ผลทดสอบ:** ☐ ข้อมูลครบทุกข้อ ☐ พบข้อมูลหาย/ผิด (ระบุข้อ)

| ข้อ | อาการ | ข้อมูลที่ตรวจ | สาเหตุที่พบ | งานต่อ |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

**หมายเหตุด้านความปลอดภัย:** การทดสอบข้อ 7 ต้องทำในเครื่องทดสอบเท่านั้น ห้ามทำกับเซิร์ฟเวอร์ที่มีผู้เล่นจริงโดยไม่มี backup
