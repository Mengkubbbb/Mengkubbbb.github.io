# Checklist: Server Startup (เซิร์ฟเวอร์เริ่มทำงานสะอาด)

**ใช้เมื่อ:** ทุกครั้งที่เปลี่ยนปลั๊กอิน เวอร์ชัน Paper หรือค่าใน `server.properties`
**คัดลอกไปไว้:** `docs/test-runs/YYYY-MM-DD-server-startup.md`

| # | รายการตรวจ | ผ่าน? | หลักฐาน |
| --- | --- | --- | --- |
| 1 | รันคำสั่งเริ่มเซิร์ฟเวอร์ (เช่น `./start.sh`) | ☐ | คำสั่ง: |
| 2 | เซิร์ฟเวอร์แจ้งเวอร์ชันที่ถูกต้อง (Paper + Minecraft) | ☐ | บรรทัด log: |
| 3 | เวอร์ชัน Java ที่ใช้ตรงกับที่เอกสารกำหนด | ☐ | `java -version` → |
| 4 | ไม่มีบรรทัด `ERROR` หรือ `SEVERE` ใน 60 วินาทีแรก | ☐ | log: |
| 5 | ไม่มี `WARN` ที่เกี่ยวกับปลั๊กอินของเรา | ☐ | log: |
| 6 | ปลั๊กอินของเราโหลดขึ้นว่า enabled | ☐ | log: |
| 7 | รับคำสั่งจาก console ได้ (เช่น `/help`) | ☐ | ผลลัพธ์: |
| 8 | TPS เริ่มต้นที่ 20.0 | ☐ | `/tps` → |
| 9 | ปิดเซิร์ฟเวอร์ด้วย `stop` ได้สะอาด (ไม่ถูก kill) | ☐ | log: |
| 10 | เปิดซ้ำอีกครั้งแล้วข้อมูลโลกยังอยู่ | ☐ | ไฟล์/เวลา: |

**สรุปผล:** ☐ ผ่านทั้งหมด ☐ ผ่านบางส่วน (ระบุข้อที่ตก) ☐ ไม่ผ่าน
