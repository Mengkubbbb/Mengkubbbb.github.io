# exercises/ — วิธีทำและส่งแบบฝึกหัด

> ✍️ แบบฝึกหัดอยู่ในบทเรียนแต่ละวัน (หัวข้อ G) ไฟล์นี้บอกว่า **ต้องทำอะไรกับคำตอบ**

---

## 1. กติกา 3 ข้อของแบบฝึกหัด

1. **ทำก่อนดูเฉลยเสมอ** — ถ้าติดเกิน 15 นาที ให้พิมพ์ `HINT` (คำใบ้) ก่อน และใช้ `SOLUTION` เมื่อต้องการเฉลยจริง ๆ
2. **ส่งงานพร้อมหลักฐาน** — ทุกคำตอบต้องแนบคำสั่งที่รัน + ผลลัพธ์ที่เห็นจริง (คัดลอกจาก Terminal)
3. **ไม่เข้าใจให้บอกตรง ๆ** — ตอบว่า "ยังไม่เข้าใจข้อ 2" มีค่ากว่าก๊อปคำตอบถูก ๆ มา

---

## 2. ส่งงานอย่างไร

### วิธีที่ 1: พิมพ์ในแชท (เร็วที่สุด)
```text
Day 02 · แบบฝึกหัดพื้นฐาน
คำสั่ง: ./scripts/greet.sh Somchai
ผลลัพธ์: สวัสดี Somchai ยินดีต้อนรับสู่ Eclipse MMO
ปัญหาที่เจอ: ครั้งแรกได้ Permission denied แก้ด้วย chmod +x
```

### วิธีที่ 2: เขียนไฟล์เก็บไว้ (ดีที่สุดสำหรับการย้อนดู)
สร้างไฟล์ใหม่ที่ `exercises/submissions/day-XX.md` โดยใช้เทมเพลตด้านล่าง

**พาธไฟล์:** `Minecraft-MMO-Academy/exercises/submissions/day-02.md` (สร้างโฟลเดอร์ `submissions/` เองได้)

```markdown
# Day 02 — แบบฝึกหัด

    (วางผลลัพธ์)

## 2. ประยุกต์: ...

สิ่งที่เพิ่มเข้าไป: ...
ผลการทดสอบ: ...

## 3. คำถามตรวจสอบความเข้าใจ
1) ...
2) ...
3) ...

## 4. Challenge
ทำได้/ยังไม่ได้ เพราะ ...

## ปัญหาที่เจอและวิธีแก้
- อาการ: ... → แก้ด้วย: ...
```

## 3. เทมเพลตคำตอบ (คัดลอกใช้)

| หัวข้อ | ต้องมีอะไร |
| --- | --- |
| พื้นฐาน | คำสั่ง + ผลลัพธ์ + ไฟล์ที่สร้าง |
| ประยุกต์ | คำอธิบายว่าดัดแปลงอะไรจากตัวอย่าง + ผลทดสอบ |
| คำถามตรวจสอบ 3 ข้อ | ตอบด้วยคำของตัวเอง 1–3 ประโยคต่อข้อ |
| Challenge | แนวคิด + สิ่งที่ทดลอง + ผลที่ได้ (ทำไม่สำเร็จก็ส่งได้) |

## 4. แบบฝึกหัดของช่วงแรก (Day 01–07)

แบบฝึกหัดเต็มอยู่ในบทเรียนแต่ละวัน สรุปสั้น ๆ เพื่อวางแผนเวลา:

| Day | พื้นฐาน | ประยุกต์ | Challenge |
| --- | --- | --- | --- |
| 01 | สร้างโฟลเดอร์ตามโครงและแสดงผลด้วย `tree` | เพิ่มโฟลเดอร์ของโปรเจกต์ตัวเอง + เขียน README | ออกแบบโครงให้รองรับ 3 เซิร์ฟเวอร์ (dev/stage/prod) |
| 02 | เขียน script แรกที่พิมพ์ข้อความต้อนรับ | เพิ่มการรับ argument และตรวจสอบค่าว่าง | ทำ script ให้สำรองไฟล์ + ตั้งชื่อไฟล์ตามวันที่ |
| 03 | ตั้ง alias 3 ตัวและทดสอบ | หาไฟล์ด้วยชื่อ/เวลา/ขนาด | ทำ `/etc/hosts`-free local hostname test (ไม่ต้อง sudo) |
| 04 | ติดตั้ง VS Code extension + JDK | รัน `java -version` และ `javac -version` ให้ตรงกัน | เขียนสคริปต์เช็กเวอร์ชัน Java ที่ถูกต้อง |
| 05 | สร้าง repo + commit แรก | สร้าง branch แก้ README แล้ว merge | จัด `.gitignore` ให้เหมาะกับโปรเจกต์ Java |
| 06 | วาดผังการทำงานระบบสุ่มรางวัล | แปลงผังเป็น pseudocode | ออกแบบผังระบบสกิล (cooldown + mana) |
| 07 | ทบทวน 6 วัน + เขียน `server-check.sh` | เพิ่มการตรวจพอร์ต/ดิสก์/RAM | ทำ script รายงานผลเป็นไฟล์ log ตามวันที่ |

## 5. การให้คะแนน (ครูใช้ตรวจ)

| เกณฑ์ | 1 คะแนน | 3 คะแนน | 5 คะแนน |
| --- | --- | --- | --- |
| ความถูกต้อง | รันไม่ผ่าน | ผ่านตามตัวอย่าง | ผ่านและดัดแปลงได้เอง |
| ความเข้าใจ | ก๊อปมา | อธิบายได้ | อธิบายได้ + แก้ปัญหาที่เกิดเองได้ |
| การทดสอบ | ไม่ได้ทดสอบ | ทดสอบแล้ว 1 กรณี | ทดสอบกรณีปกติ + ขอบ |
| การบันทึก | ไม่บันทึก | บันทึกใน PROGRESS.md | บันทึก + เจอ error ใหม่ที่บันทึกลง TROUBLESHOOTING.md |
